# Acusttel

Rediseño estático de demostración de [acusttel.com](https://acusttel.com/), hecho con Astro para publicarse en GitHub Pages.

La URL prevista es `https://xlu1s.github.io/web-acusttel/`.

## Desarrollo

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

El inventario del sitio original está en `docs/inventario.md`.
